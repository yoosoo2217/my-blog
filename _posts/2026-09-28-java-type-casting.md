[이전 글]({{ site.baseurl }}/java-variables-and-types.html)에서 변수와 자료형을 정리했고, 이번엔 서로 다른 자료형 사이에서 값을 주고받을 때 필요한 형변환을 정리한다.

## 1. 형변환이란

형변환은 어떤 자료형의 값을 다른 자료형으로 바꾸는 과정이다.

```text
int → double
double → int
char → int
```

## 2. 묵시적 형변환 (자동)

```java
int num = 100;
double dnum = num; // 자동 변환
```

`int`처럼 정수 자료형의 값을 `double`처럼 범위가 더 넓은 실수 자료형에 담을 때는, 자바가 별도 표시 없이 자동으로 변환해준다. 다만 이건 "작은 자료형 → 큰 자료형이면 항상 값이 완벽하게 보존된다"는 뜻은 아니다. 아주 큰 `long` 값을 `float`이나 `double`로 자동 변환하면, 자료형 크기는 더 커져도 정밀도가 떨어져 정확한 값이 아닐 수 있다. 지금 단계에서는 "정수를 실수로 바꾸는 것처럼, 표현 범위가 넓어지는 방향의 변환은 자동으로 된다" 정도로 알아두면 충분하다.

## 3. 명시적 형변환 (직접 지정)

```java
double dnum = 99.99;
int inum = (int)dnum;
```

```text
dnum = 99.99
inum = 99
```

큰 자료형(`double`)의 값을 더 작은 자료형(`int`)으로 바꿀 때는 소수점 이하가 잘려나가는 것처럼 데이터 손실이 생길 수 있다. 그래서 자바는 이 변환을 자동으로 해주지 않고, `(int)`처럼 괄호로 자료형을 써서 "이 손실을 감수하고 바꾸겠다"는 의사를 개발자가 직접 표시하도록 한다.

## 4. char와 숫자

```java
char a = 'a';
int num = a;

System.out.println(a + 1);
```

```text
98
```

문자 `'a'`는 내부적으로 유니코드 값 97로 저장되어 있어서, `a + 1`은 `98`이 된다. 문자는 내부적으로 정수(유니코드 코드 값)로 저장되어 있기 때문에 `int`로 변환되거나 숫자 연산에 사용될 수 있다. 다만 "문자는 곧 숫자다"라고 단순화하기보다는, `char`가 정수형으로 변환될 수 있는 자료형이라는 정도로 이해하는 게 정확하다.

## 5. String은 단순 캐스팅으로 바뀌지 않는다

```java
String str = "Hello";
// int num = (int)str; // X - 컴파일 에러
```

`(int)`처럼 괄호로 감싸는 캐스팅은 숫자 자료형끼리, 혹은 서로 관련 있는 타입 사이에서만 동작한다. `String`과 `int`는 이런 관계가 아니기 때문에 단순 캐스팅으로는 변환되지 않고, `Integer.parseInt(str)`처럼 별도의 변환 방법이 필요하다.

## 6. 형변환을 쓰는 이유

형변환의 핵심은 서로 다른 자료형의 값을, 지금 필요한 자료형으로 바꿔서 함께 쓸 수 있게 하는 것이다. 예를 들어 계산은 `double`로 했지만 결과를 담을 변수는 `int`여야 하는 경우처럼, 자료형이 서로 맞지 않을 때 형태를 맞춰준다.

그중에서도 표현 범위가 더 좁은 자료형으로 바꾸는 경우(예: `double` → `int`, `long` → `int`)는 값이 표현 범위를 벗어나거나 소수점이 잘리는 등 데이터 손실 가능성이 있다. 그래서 이런 변환만 `(int)`처럼 명시적으로 표시하도록 자바가 요구한다.

## 오늘 정리

- 형변환은 "자동으로 되는 경우"(묵시적)와 "직접 표시해야 하는 경우"(명시적)로 나뉘고, 그 기준은 값 손실 위험이 있는지였다.
- `char`가 숫자로 취급될 수 있다는 게 가장 낯설었는데, 문자가 내부적으로 정수값(유니코드)으로 저장돼 있다는 걸 알고 나니 이해가 됐다.
- `String`은 괄호 캐스팅으로 바뀌지 않는다는 것도 처음 알았다 — 숫자 자료형끼리의 변환과는 다른 문제라는 걸 배웠다.

## 더 학습하면 좋은 개념

- **래퍼 클래스(Wrapper Class)와 파싱** — `Integer.parseInt()`처럼 문자열을 숫자로 바꾸는 메서드들이 속한 개념이다. 기본형과 이 클래스들이 어떻게 연결되는지 알면 형변환의 범위가 더 넓어진다.
- **오토박싱/언박싱(Autoboxing/Unboxing)** — 기본형(`int`)과 래퍼 클래스(`Integer`) 사이의 자동 변환으로, 오늘 배운 형변환과는 조금 다른 개념이라 구분해서 알아두면 좋을 것 같다.
- **유니코드(Unicode)** — `char`가 정수로 변환될 수 있는 이유의 근본 원리다. 문자마다 어떤 숫자 코드가 매겨져 있는지 알면 문자 연산이 더 명확해진다.
