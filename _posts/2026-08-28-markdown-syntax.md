블로그 글을 쓸 때마다 제목, 목록, 링크, 코드 블록 문법을 다시 찾아보게 된다.  
자주 쓰는 마크다운 문법을 실제 예시와 함께 한 번에 정리해 둔다.

> **TL;DR**
> - 제목은 `#` 개수로, 강조는 `**`와 `*`로 표시한다.
> - 목록, 링크, 이미지, 인용, 코드 블록, 표 모두 기호 몇 개로 만든다.
> - 표는 `|`로 칸을 나누고, 두 번째 줄에 `---`를 넣는다.

## 제목과 글자 강조

제목은 `#` 개수로 단계를 만든다.  
`#`이 많아질수록 글씨가 점점 작아진다.

- `**굵은 글씨**` : **굵은 글씨**
- `*기울임*` : *기울여* 쓸 수 있다.

## 목록 만들기

순서가 없는 목록은 `-` 또는 `*`로 만든다.  
들여쓰기를 하면 하위 항목이 된다.

- 첫 번째
- 두 번째
* 세 번째
* 네 번째
    * 4-1번째

순서가 있는 목록은 숫자와 점으로 만든다.

1. 하나
2. 둘

## 링크와 이미지 첨부

링크는 `[표시 텍스트](주소)`, 이미지는 앞에 `!`를 붙여 `![대체 텍스트](경로)`로 쓴다.

* [나의 깃허브](https://github.com/yoosoo2217/GitGui-Test.git)
* ![인력사무소 8월 28일 점심](image.png)

## 인용 구문

인용하는 구문은 꺾쇠(`>`)로 만든다.  
남의 말이나 정의를 옮길 때 사용한다.

> 인용하는 구문은 꺾쇠로 만든다.
> 남의 말이나 정의를 옮길 때 사용한다.

## 백틱과 코드 블록

* `` ` `` 은 1 옆에 있는 키로, 백틱이라고 부른다.
* 백틱 내부에는 코드나 명령어를 적는다.

```bash
git status
git init
```

## 표 만들기

표는 `|`로 칸을 나눈다.  
`|`는 개발 쪽에서 OR 연산자로도 쓰이는 기호다.

|명령어|하는 일|
|---|---|
|`git add`|스테이징 영역에 파일 추가|
|`git commit`|로컬 저장소에 저장|

## 정리

- 제목(`#`), 강조(`**`, `*`), 목록(`-`, `*`, 숫자), 인용(`>`)은 기호를 앞에 붙이는 방식이다.
- 링크는 `[]()`, 이미지는 `![]()`이고, 코드는 백틱으로 감싼다.
- 표는 `|`와 `---` 줄로 만든다. 다음에는 Mermaid 다이어그램도 정리해 볼 예정이다.
