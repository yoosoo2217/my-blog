[이전 글]({{ site.baseurl }}/java-program-execution.html)에서 자바 코드가 실행되는 과정을 정리했고, 이번엔 그 코드 안에서 값을 다루는 가장 기본 단위인 변수와 자료형을 정리한다.

## 1. 변수란 — 값이 아니라 "공간"

변수는 값을 저장하기 위한 **공간에 이름을 붙여 사용하는 것**이다. 변수 자체를 값이라고 생각하기보다는, "값을 담는 자리"라고 이해하는 게 먼저다.

```java
int age = 20;
```

- `int` = 자료형(공간의 종류)
- `age` = 변수 이름(공간의 이름)
- `20` = 값(리터럴)

## 2. 리터럴

리터럴은 코드에 직접 써넣은 값 그 자체다. 종류는 이렇게 나뉜다.

- 정수 리터럴: `10`
- 실수 리터럴: `3.14`
- 문자 리터럴: `'a'`
- 문자열 리터럴: `"hi"`
- 논리 리터럴: `true`, `false`

## 3. 정수 자료형

```java
byte b = 10;
short s = 10;
int i = 10;
long l = 10;
```

자료형마다 차지하는 크기가 다르다(1 byte = 8 bit).

| 자료형 | 크기 |
|---|---|
| `byte` | 1 byte |
| `short` | 2 byte |
| `int` | 4 byte |
| `long` | 8 byte |

`byte`는 1바이트(8비트)라서 표현 범위가 `-128 ~ 127`로 좁다. `int`는 4바이트(32비트)라서 표현할 수 있는 값의 가짓수가 2<sup>32</sup>개(약 42억 개)이며, 이 42억 개를 양수와 음수로 나눠서 대략 `-21억 ~ 21억` 범위를 표현한다.

수업에서는 "자료형마다 표현할 수 있는 값의 범위와 차지하는 크기가 다르다"는 걸 배웠고, 그래서 다루려는 값이 어느 범위인지에 맞춰 자료형을 골라 써야 한다고 배웠다. 예를 들어 나이처럼 작은 범위의 값이면 `int`로도 충분하지만, 그보다 훨씬 큰 값을 다뤄야 한다면 표현 범위가 더 넓은 `long`이 필요하다.

## 4. 실수 자료형

```java
float f = 3.14f;
double d = 3.14;
```

| 자료형 | 크기 |
|---|---|
| `float` | 4 byte |
| `double` | 8 byte |

`float` 리터럴 뒤에 `f`를 붙이는 이유가 있다. 자바에서 소수 리터럴의 기본 타입은 `double`이기 때문에, `float` 변수에 소수 리터럴을 그냥 대입하면 "더 큰 자료형(double)을 더 작은 자료형(float)에 대입"하는 셈이 되어 컴파일 오류가 난다. `f`를 붙이면 이 리터럴이 `float`라는 걸 명시하게 되어 문제없이 대입할 수 있다.

## 5. 문자와 문자열

### char — 문자 하나

```java
char ch = 'ㅎ';
```

`char`는 문자 하나만 저장한다. 그래서 아래 코드는 컴파일되지 않는다.

```java
char ch = 'ㅎ2'; // X - char는 문자 하나만 담을 수 있어 컴파일 에러
```

### String — 문자열

```java
String str = "안녕하세요!";
```

`String`은 여러 문자로 이루어진 문자열을 저장한다. `char`가 문자 하나를 담는 그릇이라면, `String`은 그 문자들을 이어 붙인 문장을 담는 그릇이라는 차이가 있다.

같은 블록(`{ }`) 안에서는 같은 이름의 변수를 다시 선언할 수 없다.

```java
{
    String str = "안녕하세요!";
    String str = "다시 선언"; // X - 같은 스코프에서 변수명 중복 불가, 컴파일 에러
}
```

## 6. boolean

```java
boolean isStudent = true;
boolean isAdult = false;
```

`boolean`은 참/거짓만 표현하며, 가능한 값은 `true`와 `false` 둘뿐이다.

## 7. 변수 선언과 초기화 구분

다음 세 가지는 서로 다른 동작이다.

```java
int num;         // 선언
num = 30;        // 값 대입
int num2 = 10;   // 선언과 동시에 초기화
```

## 8. 대입 연산자 `=`

`=`를 기준으로 왼쪽은 값을 담을 **공간**(변수), 오른쪽은 그 공간에 넣을 **값**이다.

```java
int y = 10;
int z = y;
```

`z = y`는 "y라는 변수 자체를 z에 옮겨 담는다"는 뜻이 아니라, **y가 가지고 있는 값을 읽어서 z라는 공간에 대입한다**는 뜻이다. 그래서 이후 `y`의 값이 바뀌어도 이미 대입이 끝난 `z`에는 영향을 주지 않는다.

## 오늘 정리

- 변수는 "이름 붙은 저장 공간"이라는 감을 잡는 게 먼저였고, 그 공간에 넣을 수 있는 값의 형태가 자료형이었다.
- 정수·실수 자료형은 크기(byte)에 따라 표현 범위가 다르고, 저장할 값에 맞춰 골라 써야 한다는 걸 배웠다.
- `=`는 "왼쪽 공간에 오른쪽 값을 넣는다"는 방향성이 있다는 게 가장 헷갈렸다가 정리된 부분이었다.

## 더 학습하면 좋은 개념

- **참조 타입과 기본 타입** — 오늘 다룬 자료형은 모두 기본형(primitive)인데, `String`처럼 기본형이 아닌 타입은 변수에 값이 아니라 "주소"가 저장된다는 점이 다르다. 대입 연산자의 동작이 어떻게 달라지는지 다음에 확인해보고 싶다.
- **오버플로우(Overflow)** — `byte`, `int`처럼 크기가 정해진 자료형은 표현 범위를 벗어나는 값을 넣으면 어떻게 되는지 실습으로 확인해보면 "크기에 맞춰 자료형을 고른다"는 말의 의미가 더 와닿을 것 같다.
- **유니코드와 char** — `char`가 `'ㅎ'` 같은 한글 한 글자도 담을 수 있는 이유는 자바의 `char`가 유니코드 기반이기 때문이다. 문자 인코딩 개념과 연결해서 더 알아보고 싶다.
