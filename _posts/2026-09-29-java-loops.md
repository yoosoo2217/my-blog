## 1. for문 — 정해진 횟수만큼 반복하기

`for`문은 초기식, 조건식, 증감식을 사용해서 반복 횟수를 제어하는 반복문이다.

```text
for(초기식; 조건식; 증감식) {실행코드}
```

- 초기식: 반복에 쓰이는 변수의 초기값을 설정한다.
- 조건식: 참이면 반복하고, 거짓이면 종료한다.
- 증감식: 한 번 반복한 뒤 변수의 값을 바꾼다.

벤치프레스를 반복하면서, 홀수 번째에만 말을 걸고 짝수 번째는 넘어가는 코드로 연습했다.

```java
System.out.println("성원님 벤치프레스 5회 실시할게요!");

for (int i = 1; i < 5; i++) {
    if (i % 2 == 0) {
        System.out.println("방임중..");
    } else {
        System.out.println("성원님" + i + "번 했습니당");
    }
}
```

```text
성원님 벤치프레스 5회 실시할게요!
성원님1번 했습니당
방임중..
성원님3번 했습니당
방임중..
```

반복문 안에 조건문을 넣어서 "짝수 번째면 방임, 홀수 번째면 말 걸기"라는 요구사항을 구현했다.

### 주의할 점 — 실제 반복 횟수는 5회가 아니라 4회다

안내 문구는 "5회 실시할게요"지만, 조건식이 `i < 5`이고 `i`가 1부터 시작하기 때문에 실제로 실행되는 건 `i`가 1, 2, 3, 4일 때뿐이라 **총 4번만 반복**된다. 의도한 대로 5번을 채우려면 조건을 `i <= 5`(또는 `i < 6`)로 고쳐야 한다. 반복문에서는 시작값과 조건식의 부등호(`<`, `<=`) 조합에 따라 반복 횟수가 한 번씩 어긋나는 실수(오프바이원, off-by-one)가 생기기 쉽다는 걸 이 코드로 직접 확인했다.

## 2. while문 — 조건이 참인 동안 반복하기

`while`은 조건식이 참인 동안 실행 코드를 반복한다.

```text
while(조건식) {실행코드, 증감식}
```

반복 횟수가 불확실하거나, 조건에 따라 반복을 끝내야 할 때 사용한다.

```java
int count = 0;
while (count <= 5) {
    System.out.println("카운트펀치" + count);
    count++;
}
```

```text
카운트펀치0
카운트펀치1
카운트펀치2
카운트펀치3
카운트펀치4
카운트펀치5
```

`for`와 달리 초기식(`count = 0`)과 증감식(`count++`)이 `while` 형식 안에 포함되어 있지 않아서, 반복문 밖과 안에 직접 챙겨 써야 한다.

## 3. do-while문 — 최소 한 번은 실행하고 조건을 검사하기

`do-while`은 실행 코드를 최소 1회 실행한 뒤에 조건식을 확인하는 반복문이다.

```text
do{실행 코드} while(조건식);
```

```java
int num = 0;

do {
    System.out.println("0~2까지 반복 출력 : " + num);
    num++;
} while (num > 3);
```

```text
0~2까지 반복 출력 : 0
```

### 주의할 점 — 출력이 "0, 1, 2"로 이어지지 않는 이유

`do-while`은 코드를 먼저 한 번 실행한 뒤에야 조건을 검사한다. 여기서는 `num`이 0으로 시작해서 첫 실행 직후 조건 `num > 3`을 검사하는데, `0 > 3`은 처음부터 거짓이므로 반복은 **딱 한 번만 일어나고 즉시 종료**된다. 출력 문구는 "0~2까지 반복 출력"이지만, 실제로는 0, 1, 2가 차례로 찍히지 않고 `num`이 0일 때 한 줄만 출력된다. 0부터 2까지 반복하려는 의도였다면 조건은 `num > 3`이 아니라 `num < 3`(또는 `num <= 2`)이어야 한다.

반대로 이 코드는 `do-while`의 핵심 특징 — "조건과 무관하게 최소 1회는 실행된다" — 을 보여주는 좋은 사례이기도 하다. 조건(`num > 3`)이 시작부터 거짓인데도 본문이 한 번은 실행됐기 때문이다. 만약 `for`나 `while`이었다면 조건을 먼저 검사하므로 단 한 번도 실행되지 않았을 것이다.

## 4. 세 반복문 비교

| 반복문 | 조건 검사 시점 | 최소 실행 횟수 | 적합한 상황 |
|---|---|---|---|
| `for` | 반복 전 | 0회 | 반복 횟수가 정해져 있을 때 |
| `while` | 반복 전 | 0회 | 조건에 따라 반복 횟수가 유동적일 때 |
| `do-while` | 반복 후 | 1회 | 조건과 무관하게 최소 1번은 실행해야 할 때 |

## 오늘 정리

- `for` / `while` / `do-while` 모두 "조건이 참인 동안 반복한다"는 점은 같지만, `for`는 반복 횟수가 정해져 있을 때, `while`은 조건에 따라 유동적으로 반복할 때, `do-while`은 최소 1회 실행을 보장해야 할 때 쓴다는 차이를 정리했다.
- 조건식의 부등호와 시작값 조합을 잘못 맞추면 의도한 반복 횟수와 실제 반복 횟수가 어긋난다는 걸 오늘 만든 두 예제(for문의 오프바이원, do-while의 조건 오류)에서 직접 확인했다.

## 더 학습하면 좋은 개념

- **break / continue** — 반복문 도중 흐름을 강제로 끝내거나(`break`) 한 번 건너뛰는(`continue`) 제어 키워드다. 오늘 만든 반복문은 모두 끝까지 다 도는 형태라서, 중간에 멈추거나 건너뛰는 경우를 다음에 익혀야 할 것 같다.
- **향상된 for문(for-each)** — 배열이나 컬렉션을 순회할 때 초기식·조건식·증감식 없이 쓰는 문법이다. 오늘 배운 기본 `for`문의 다음 단계로 자연스럽게 이어진다.
- **중첩 반복문(nested loop)** — 반복문 안에 반복문을 넣는 구조다. 오늘은 반복문 안에 `if`문만 넣어봤는데, 반복문을 하나 더 넣는 경우도 궁금해졌다.
