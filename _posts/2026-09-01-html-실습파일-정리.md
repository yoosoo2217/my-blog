## 1. 제목 세 단계 — 첫 페이지

`h1`, `h2`, `h3`로 제목의 단계를 나누는 연습.

```html
<h1>박유수</h1>
<h2>프론트엔드를 배우는 중</h2>
<h3>좋아하는 것</h3>
```

## 2. 문단 세 개 — 자기소개

`p` 태그로 문단을 나누는 연습.

```html
<p>안녕하세요. 키즈카페에서 일하다가 개발을 시작했습니다.</p>
<p>지금은 부트캠프에서 HTML을 배우고 있습니다.</p>
<p>언젠가 제 손으로 서비스를 만드는 것이 목표입니다.</p>
```

## 3. 점이 붙는 목록 — 좋아하는 것

`ul` + `li`로 순서 없는 목록 만들기.

```html
<ul>
    <li>산책 하기</li>
    <li>노래 듣기</li>
    <li>노래 들으며 산책</li>
    <li>공포라디오 듣기</li>
    <li>집안일 하기</li>
</ul>
```

## 4. 숫자 붙는 목록 — 배우고 싶은 순서

`ol` + `li`로 순서 있는 목록 만들기.

```html
<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
    <li>그 다음은 아직 모릅니다.</li>
</ol>
```

## 5. 링크 세 개 — 자주 가는 곳

`a href`로 외부 링크 연결하기.

```html
<a href="https://www.google.com">구글 검색</a>
<a href="https://github.com">github</a>
<a href="https://yoosoo2217.github.io/my-blog/">내 블로그!</a>
```

## 6. 사진과 대체 텍스트 — 내 사진

`img`와 `alt` 속성 연습.

```html
<img src="sample/image/forest1.PNG" alt="내 프로필 사진">
```

## 7. 글자를 꾸미는 태그 — 겨울 패딩 점퍼

`s`(취소선), `b`(굵게), `i`(기울임), `sup`(위 첨자) 연습.

```html
<hr>
<h1>겨울 패딩 점퍼</h1>
<p>정가 <s>129,000</s> -> <b>89,000</b></p>
<h4>소재</h4>
<p>겉감 <i>폴리에스터</i> 100%, 충전재 거위털 80%</p>
<p>보관 시 1m<sup>2</sup> 이상 공간을 두세요.</p>
```

## 8. 표의 뼈대 — 배송비 안내

`table`, `tr`, `th`, `td`로 기본 표 만들기.

```html
<caption>주문 금액별 배송비</caption>
<table border="2">
    <tr>
        <th align="center">주문 금액</th>
        <th align="center">기본 배송비</th>
        <th align="center">도서산간 추가</th>
    </tr>
    <tr>
        <td align="center">3만원 미만</td>
        <td align="center">3,000원</td>
        <td align="center">3,000원</td>
    </tr>
    <tr>
        <td align="center">3만원 이상</td>
        <td align="center">무료</td>
        <td align="center">3,000원</td>
    </tr>
    <tr>
        <td align="center">10만원 이상</td>
        <td align="center">무료</td>
        <td align="center">무료</td>
    </tr>
</table>
```

## 9. div/span — 묶는 방법 두 가지

같은 목록을 `div`(블록)와 `span`(인라인)으로 각각 묶어본 비교.

```html
<h2>div로 묶으면</h2>
<div>커피 내리기</div>
<div>영화 보기</div>
<div>주말 산책</div>

<h2>span으로 묶으면</h2>
<p>
  <span>커피 내리기</span>
  <span>영화 보기</span>
  <span>주말 산책</span>
</p>
```

## 10. 화면 보고 HTML 만들기 — 상품 사용 영상

`video`, `audio` 태그와 `controls` 속성 연습.

```html
<video src="sample/video/video1.mp4" controls="controls"></video>
<audio src="sample/audio/major.mp3" controls="controls"></audio>
```

## 11. 소개 화면 그대로 만들기

주어진 화면을 보고 그대로 재현하는 연습. 제목, 문단, 목록, 순서 목록을 조합했다.

```html
<h1>박서준</h1>
<p>부트캠프에서 웹을 배우고 있습니다.</p>
<h4>좋아하는 것</h4>
<ul>
    <li>조롱하기</li>
    <li>욕하기</li>
    <li>시비걸기</li>
</ul>
<h4>배우고 싶은 순서</h4>
<ol>
    <li>돈 많이 버는 법</li>
    <li>무인도에서 살아남는 법</li>
    <li>부트캠프에서 살아남는 법</li>
</ol>
```

## 12. 링크가 들어간 목록 — 바로가기

`li` 안에 `a`를 넣어 클릭 가능한 목록 만들기.

```html
<h4>바로가기</h4>
<ul>
    <li><a href="https://www.google.com">구글 검색</a></li>
    <li><a href="https://github.com">깃허브</a></li>
    <li><a href="https://dyryoo316.github.io/my-blog/">내 블로그</a></li>
</ul>
```

## 13. 사진이 붙은 목록 — 좋아하는 것 3가지

`li` 안에 텍스트와 `img`를 함께 넣는 연습.

```html
<h4>좋아하는 것</h4>
<ul>
    <li>꽃<img src="sample/image/flower4.PNG" alt="꽃"></li>
    <li>딸기<img src="sample/image/strawberry.png" alt="딸기"></li>
    <li>도시<img src="sample/image/city1.PNG" alt="도시"></li>
</ul>
```

## 14. 망가진 화면 되돌리기

의도적으로 깨진 페이지를 원래 모습으로 고쳐보는 연습이었다.

```html
<h1>박까미</h1>
<p>야옹냥아옹먀아(안녕하세요. 고칠 곳 따위 없습니다)</p>
<h3>좋아하는 것</h3>
<ul>
    <li>츄르</li>
    <li>햇빛</li>
    <li>하얀색이불</li>
</ul>
<h3>링크</h3>
<a href="https://www.google.com">취미 페이지</a>
```

## 15. 칸을 가로로 합치기 — 배송 안내

`colspan`으로 셀을 가로로 병합하는 연습.

```html
<h2>배송 안내</h2>
<caption>지역별 도착 예정일</caption>
<table border="2">
    <tr>
        <th>지역</th>
        <th>평일 주문</th>
        <th>주말 주문</th>
    </tr>
    <tr>
        <td>서울·경기</td>
        <td>다음 날 도착</td>
        <td>월요일 도착</td>
    </tr>
    <tr>
        <td>그 외 지역</td>
        <td colspan="2">2~3일 소요</td>
    </tr>
    <tr>
        <td colspan="3">제주·도서산간은 하루 더 걸립니다.</td>
    </tr>
</table>
```

## 16. 칸을 세로로 합치기 — 주간 시간표

`rowspan`으로 셀을 세로로 병합하는 연습.

```html
<h1>주간 시간표</h1>
<caption>이번 주 강의 일정</caption>
<table border="2">
    <tr>
        <td>시간</td>
        <td>월요일</td>
        <td>화요일</td>
    </tr>
    <tr>
        <td rowspan="2">오전</td>
        <td>HTML기초</td>
        <td>표 만들기</td>
    </tr>
    <tr>
        <td>목록 태그</td>
        <td>칸 합치기</td>
    </tr>
    <tr>
        <td rowspan="2">오후</td>
        <td>자율 실습</td>
        <td>자율 실습</td>
    </tr>
    <tr>
        <td>질문 시간</td>
        <td>질문 시간</td>
    </tr>
</table>
```

## 17. 영역으로 묶고 영상 얹기 — 상품 사용법 안내

`hr`로 구역을 나누고, `video`/`audio`에 `loop` 속성을 추가하고, `pre`로 후기를 그대로 보여주는 연습.

```html
<h1>오늘의 마켓 상품 사용법</h1>
<p>처음 쓰는 분을 위한 3분 요약 영상입니다.</p>
<hr>
<h3>영상으로 보기</h3>
<video src="sample/video/video1.mp4" controls="controls" loop="loop"></video>
<p>소리만 듣고 싶다면 아래를 재생하세요.</p>
<audio src="sample/audio/major.mp3" controls="controls" loop="loop"></audio>
<hr>
<h3>먼저 본 분들의 한 마디</h3>
<pre>     설명이 짧아서 좋았습니다</pre>
<p>문의: 1234-5678</p>
```

## 18. 상품 소개 화면 통째로 — 핸드드립 커피 세트

제목, 이미지, 문단, 목록, 순서 목록, 링크 목록을 모두 조합해 하나의 상품 소개 페이지를 만드는 종합 연습.

```html
<h1>핸드드립 커피 세트</h1>
<h3>집에서 내리는 첫 잔</h3>
<img src="sample/image/city1.PNG" alt="커피">
<p>원두를 갈아 직접 내려 마시는 도구를 한 상자에 담았습니다.</p>
<p>처음 커피를 내려보는 사람도 바로 시작할 수 있습니다.</p>
<h4>구성품</h4>
<ul>
    <li>드리퍼</li>
    <li>종이 필터 100장</li>
    <li>서버</li>
    <li>계량 스푼</li>
</ul>
<ol>
    <li>물을 90도까지 끓입니다.</li>
    <li>필터를 드리퍼에 올립니다.</li>
    <li>원두 가루를 고르게 폅니다.</li>
    <li>가운데부터 천천히 붓습니다.</li>
</ol>
<ul>
    <li><a href="https://www.google.com">커피 추출 방법</a></li>
    <li><a href="https://www.google.com">원두 고르는 법</a></li>
</ul>
```

## 19. 3페이지 미니 사이트

여러 페이지로 이동하는 링크 목록을 만드는 연습.

```html
<h3>이동하기</h3>
<ul>
  <li><a href="01_글자관련태그.html">상품 목록</a></li>
  <li><a href="01_글자관련태그.html">연락처</a></li>
</ul>
```

```html

<caption>1주차 평가 결과</caption>
<table border="2">
    <tr>
        <th rowspan="2">이름</th>
        <th colspan="2">1주차 점수</th>
        <th rowspan="2">비고</th>
    </tr>
    <tr>
        <td>과제</td>
        <td>출석</td>
    </tr>
    <tr>
        <td>김서연</td>
        <td>90</td>
        <td>100</td>
        <td>우수</td>
    </tr>
    <tr>
        <td>박민준</td>
        <td>85</td>
        <td>95</td>
        <td>-</td>
    </tr>
    <tr>
        <td colspan="4">평균 90점 / 결석 0회</td>
    </tr>
</table>
```

## 21. 상품 비교표

표 안에 이미지와 목록을 함께 넣어 상품 두 개를 비교하는 연습.

> 원본 실습 파일에 `<td>울 코트/td>`처럼 여는 꺾쇠(`<`)가 빠진 오타가 있었다. 표가 깨지는 원인이 될 수 있어서 아래 코드에서는 `<td>`로 바로잡았다.

```html
<h2>겨울 아우터 비교</h2>
<caption>두 상품 한 눈에 보기</caption>
<table border="2">
    <tr>
        <td>상품</td>
        <td>사진</td>
        <td>특징</td>
        <td>바로가기</td>
    </tr>
    <tr>
        <td>패딩 점퍼</td>
        <td><img src="sample/image/flower1.PNG"></td>
        <td><ul>
            <li>거위털 80%</li>
            <li>무게 1.2kg</li>
        </ul></td>
        <td><a href="https://www.google.com">바로가기</a></td>
    </tr>
    <tr>
        <td>울 코트</td>
        <td><img src="sample/image/flower1.PNG"></td>
        <td><ul>
            <li>울 70%</li>
            <li>무게 1.6kg</li>
        </ul></td>
        <td><a href="https://www.google.com">바로가기</a></td>
    </tr>
    <tr>
        <td colspan="4">두 상품 모두 무료 배송입니다</td>
    </tr>
</table>
```

## 24. 들여쓰기

동작은 정상이지만 들여쓰기가 엉망인 코드를 그대로 정리하고, 링크 목록도 함께 연습했다.

```html
<h1>제임스</h1>
<h2>정리되지 않은 코드</h2>
<p>이 페이지는 동작은 정상입니다. 들여쓰기만 엉망입니다.</p>
<h3>오늘 한 일</h3>
<ul>
    <li>아침 운동</li>
    <li>HTML 공부</li>
    <li>산책</li>
</ul>
<h3>링크</h3>
<ul>
    <li><a href="01_글자관련태그.html">자기소개</a></li>
    <li><a href="01_글자관련태그.html">취미</a></li>
</ul>
```

## 25. alt를 제대로 쓰기

이미지마다 의미 있는 `alt` 텍스트를 붙이는 연습.

```html
<img src="sample/image/flower1.PNG" alt="꽃1">
<img src="sample/image/flower4.PNG" alt="꽃2">
```

## 26. 표 — 주문내역

기본 표 구조를 한 번 더 연습.

```html
<h1>주문내역</h1>
<caption>2월 주문</caption>
<table border="2">
    <tr>
        <td>주문 번호</td>
        <td>상품</td>
        <td>수량</td>
    </tr>
    <tr>
        <td>1001</td>
        <td>겨울 패딩 점퍼</td>
        <td>1</td>
    </tr>
    <tr>
        <td>1002</td>
        <td>울 코트</td>
        <td>1</td>
    </tr>
    <tr>
        <td>1003</td>
        <td>목도리</td>
        <td>2</td>
    </tr>
</table>
```

---

## 정리

- 제목/문단/목록/링크/이미지 같은 기본 태그부터, `colspan`/`rowspan`을 섞어 쓰는 복잡한 표까지 단계적으로 연습했다.
- 특히 표 병합 연습(15~23번)이 많았는데, 셀이 하나씩 늘어날 때마다 `colspan`과 `rowspan` 값을 다시 세어봐야 해서 제일 헷갈렸다.
- 21번 실습에서 `<td>울 코트/td>`처럼 여는 꺾쇠를 빠뜨리면 표 전체 레이아웃이 깨질 수 있다는 걸 직접 겪었다. 태그는 열고 닫는 짝이 정확히 맞아야 한다는 걸 몸으로 배웠다.
