## 선택자란

선택자(Selector)는 "CSS를 어떤 HTML 요소에 적용할지 고르는 규칙"이다. 아래처럼 선택자 뒤에 중괄호로 스타일을 적는다.

```css
선택자 { 속성: 값; }
```

선택자는 크게 "무엇을 기준으로 고르는가"에 따라 여러 종류로 나뉜다. 오늘 배운 것들을 기준별로 정리했다.

## 1. 기본 선택자 (전체 / 태그 / id / class)

| 선택자 | 문법 | 의미 |
|---|---|---|
| 전체 선택자 | `*` | 모든 요소 선택 |
| 태그 선택자 | `li` | 해당 태그 전부 선택 |
| id 선택자 | `#id값` | `id` 속성이 일치하는 요소 (문서 안에서 유일) |
| class 선택자 | `.class값` | `class` 속성이 일치하는 요소 (여러 개 가능) |

## 2. 속성 선택자 (Attribute Selector)

기본 선택자 뒤에 `[]`를 붙이면, 태그의 속성값을 조건으로 골라낼 수 있다.

```
선택자[속성명=속성값] { 설정 내용 }
```

실습에서는 `div`의 `name`, `class` 속성값을 여러 조건으로 골라보았다.

```html
<div name="name1 name5 name6" class="div-class">div1</div>
<div name="name2" class="div-class">div2</div>
<div name="name3" class="div-class">div3</div>
<div name="name4" class="class-div">div4</div>
```

```css
div[name=name2]   { background: orangered; }  /* 정확히 일치 */
div[name~=name1]  { background: forestgreen; } /* 공백 구분 값 중 하나 일치 */
div[class|=class] { background: darkkhaki; }   /* 일치 또는 '값-'으로 시작 */
div[name^=name]   { background: powderblue; }  /* 접두사 일치 */
div[class$=class] { background: salmon; }      /* 접미사 일치 */
div[class*=div]   { background: cadetblue; }   /* 포함 */
```

| 기호 | 의미 |
|---|---|
| `=` | 정확히 일치 |
| `~=` | 공백으로 구분된 값 중 하나가 일치 |
| `\|=` | 정확히 일치하거나, `값-`으로 시작 |
| `^=` | 특정 값으로 시작 (접두사) |
| `$=` | 특정 값으로 끝남 (접미사) |
| `*=` | 특정 값을 포함 |

## 3. 후손 선택자와 자손 선택자

| 구분 | 의미 | 문법 |
|---|---|---|
| 자손 선택자 | 바로 아래(한 단계) 요소만 선택 | `부모 > 자식` |
| 후손 선택자 | 하위에 있는 요소 전부(몇 단계든) 선택 | `조상 후손` (공백) |

```html
<div id="test1">
    <h4>자손 1번 입니다.</h4>
    <h4>자손 2번 입니다.</h4>
    <div>
        <ul id="testul">리스트
            <li>ul 태그의 자손이면서, div 태그의 후손</li>
            <li>ul 태그의 자손이면서, div 태그의 후손</li>
        </ul>
    </div>
</div>
```

```css
#test1 > h4 { background: hotpink; }   /* 바로 아래 h4만 */
#test1 ul   { background: sandybrown; } /* 몇 단계든 하위 ul 전부 */
```

`>`가 있으면 "바로 한 단계 아래"만, 공백만 있으면 "몇 단계든 하위 전부"라는 차이를 실습으로 확인했다.

## 4. 반응 선택자 (:active, :hover)

사용자의 행동에 따라 스타일이 바뀌는 선택자다.

| 선택자 | 의미 |
|---|---|
| `:active` | 사용자가 클릭하고 있는 순간 |
| `:hover` | 마우스 커서가 올라와 있는 동안 |

```html
<div id="active-test">active 테스트</div>
<div id="hover-test">hover 테스트</div>
```

```css
#active-test:active {
    background: red;
    color: white;
}

#hover-test:hover {
    cursor: pointer;
    background: darkgreen;
    color: bisque;
    font: 60px bold;
}
```

## 5. 상태 선택자 (:checked, :enabled, :disabled, :focus)

입력 양식의 상태에 따라 선택되는 선택자다.

```html
<input type="checkbox" name="fruits" value="사과" id="apple">
<label for="apple">사과</label>
<input type="checkbox" name="fruits" value="바나나" id="banana">
<label for="banana">바나나</label>

<label for="userId">아이디 : </label>
<input type="text" id="userId" placeholder="아이디 입력">

<select>
    <option value="붕어빵" disabled>붕어빵</option>
    <option value="피자빵">피자빵</option>
    <option value="모닝빵" disabled>모닝빵</option>
</select>
```

```css
input[type=checkbox]:checked { width: 100px; height: 100px; }
#userId:focus { background: hotpink; }
option:enabled { background: darkred; }
option:disabled { background: red; }
```

| 선택자 | 의미 |
|---|---|
| `:checked` | 체크박스/라디오가 선택된 상태 |
| `:focus` | 입력창에 커서가 활성화된 상태 |
| `:enabled` | 사용 가능한(활성) 입력 요소 |
| `:disabled` | `disabled` 속성이 붙어 비활성화된 요소 |

> 원본 실습 파일에 `<br>` 다음 줄에 `<`가 빠진 `hr>` 오타가 있었다. 정리하면서 `<hr>`로 바로잡았다.

## 6. 동위 선택자 (형제 관계)

동위 선택자는 부모-자식처럼 포함 관계가 아니라, **같은 부모를 둔 형제 관계**의 태그를 다루는 선택자다.

```html
<div id="div-test1">div-test1</div>
<div id="div-test2">div-test2</div>
<div id="div-test3">div-test3</div>
<div id="div-test4">div-test4</div>
<div id="div-test5">div-test5</div>
```

```css
#div-test1 { background: rgb(226, 197, 255); }
#div-test1 + div { background: rgb(255, 205, 205); } /* 바로 다음 형제 1개 */
/* #div-test1 ~ div { background: coral } */          /* 뒤따르는 형제 전부 */
```

| 선택자 | 의미 |
|---|---|
| `A + B` | A 바로 다음에 오는 형제 B **1개**만 선택 |
| `A ~ B` | A 뒤에 오는 형제 B를 **전부** 선택 |

## 7. 일반 구조 선택자 (nth-child 등)

형제들 중 "몇 번째"인지로 위치를 골라내는 선택자다.

```html
<div id="test">
    <p>테스트1</p>
    <p>테스트2</p>
    <p>테스트3</p>
    <p>테스트4</p>
    <p>테스트5</p>
    <pre>테스트6</pre>
</div>
```

```css
#test :first-child     { background: rgb(218, 252, 170); }
#test :last-child      { background: rgb(206, 206, 244); }
#test :nth-child(2)    { background: rgb(188, 235, 235); }
#test :nth-child(2n)   { background: rgb(255, 253, 228); }
#test :nth-last-child(4) { background: rgb(229, 227, 206); }
```

| 선택자 | 의미 |
|---|---|
| `:first-child` | 첫 번째 자식 |
| `:last-child` | 마지막 자식 |
| `:nth-child(n)` | 앞에서부터 n번째 (2n=짝수, 2n-1 또는 odd=홀수) |
| `:nth-last-child(n)` | 뒤에서부터 n번째 |

## 8. 부정 선택자 (:not)

지금까지의 선택 조건을 **반대로** 적용하는 선택자다. "이거 빼고 다 선택"할 때 쓴다.

```html
<div id="test2">
    <p>테스트1</p>
    <p>테스트2</p>
    <p>테스트3</p>
    <p>테스트4</p>
    <p>테스트5</p>
    <pre>테스트6</pre>
</div>
```

```css
#test2 p:not(:nth-child(2n))  { background: wheat; }
#test2 p:not(:nth-child(odd)) { background: wheat; }
```

`2n`(짝수)의 반대가 `odd`(홀수)이기 때문에, `:not(:nth-child(2n))`과 `:not(:nth-child(odd))`가 결과적으로 같은 요소를 선택한다는 걸 실습으로 확인했다.

## 9. 문자 선택자 (::first-letter, ::first-line, ::selection)

태그 전체가 아니라 **태그 안의 특정 조건의 문자**를 선택하는 선택자다. 콜론이 두 개(`::`)라는 점이 지금까지의 가상 클래스(`:hover` 등)와 다르다.

```html
<div id="test3">
    <p>절대음감절대음감</p>
</div>
```

```css
#test3 p::selection { color: brown; }
```

`::first-letter`, `::first-line`도 같은 방식으로 실습했지만, 실제로 적용해본 건 드래그 선택 스타일(`::selection`)이다.

| 선택자 | 의미 |
|---|---|
| `::first-letter` | 문단의 첫 글자 |
| `::first-line` | 문단의 첫 줄 |
| `::selection` | 사용자가 드래그로 선택한 텍스트 |

## 10. 선택자 우선순위 (Specificity)

한 요소에 여러 선택자의 스타일이 동시에 걸리면, **더 구체적인(우선순위가 높은) 선택자**가 이긴다.

```css
* {
    color: aquamarine;
}
div {
    background: darkcyan;
    color: rgb(35, 93, 59);
}
#test1 {
    background: brown;
}
.test1 {
    background: rgb(146, 232, 241);
}
#test2 {
    background: darkgray;
}
.test2 {
    background: darkgoldenrod !important;
}
```

| 우선순위 (낮음 → 높음) | 예시 |
|---|---|
| 전체 선택자 | `*` |
| 태그 선택자 | `div` |
| class / 속성 / 가상 클래스 선택자 | `.test1`, `[name=x]`, `:hover` |
| id 선택자 | `#test1` |
| 인라인 스타일 | `style="..."` |
| `!important` | 다른 모든 우선순위를 무시하고 최우선 적용 |

`#test2`(id)와 `.test2`(class)가 같은 요소에 걸리면 원래는 id가 이기지만, `.test2`에 `!important`를 붙이면 `.test2`가 이긴다는 걸 확인했다. `!important`는 우선순위 규칙 자체를 무시하는 예외라, 남용하면 나중에 스타일을 덮어쓰기 어려워진다고 배웠다.

## 막혔던 것

- 속성 선택자의 `~=`, `|=`, `^=`, `$=`, `*=` 기호가 서로 헷갈렸다. `^`(시작), `$`(끝)은 정규표현식과 기호가 같아서 그걸로 외우니 편했다.
- 자손(`>`)과 후손(공백)의 차이를 처음엔 몰라서, `#test1 > h4`와 `#test1 h4`가 같은 결과를 낼 거라고 생각했다. 실제로는 중간에 다른 태그가 끼면 결과가 달라진다.
- `:nth-child(2n)`과 `:not(:nth-child(2n))`처럼 부정 선택자와 구조 선택자를 같이 쓰는 조합이 처음엔 어려웠다.

## 오늘 정리

- 선택자를 "무엇을 기준으로 고르는가"로 나누면: 기본(전체/태그/id/class) → 속성 → 관계(자손/후손/동위) → 상태(hover/active/checked 등) → 구조(nth-child) → 부정(not) → 문자(::first-letter 등) 순으로 점점 더 세밀하게 고를 수 있다는 걸 배웠다.
- 마지막으로 배운 우선순위(Specificity) 개념 덕분에, 왜 어떤 스타일은 적용이 안 되고 다른 스타일이 이기는지 이해할 수 있게 됐다.

## 더 학습하면 좋은 개념

- **CSS 우선순위 계산법(Specificity 점수)** — 오늘은 "id가 class보다 세다" 정도로만 배웠지만, 실제로는 (인라인, id 개수, class/속성/가상클래스 개수, 태그 개수)를 점수로 계산하는 규칙이 있다. 선택자가 복잡해질수록 이 계산법을 알아야 충돌을 예측할 수 있다.
- **가상 클래스(pseudo-class) vs 가상 요소(pseudo-element)** — `:hover`처럼 콜론 1개는 가상 클래스, `::selection`처럼 콜론 2개는 가상 요소다. 이 둘의 문법적 구분과 유래를 알면 앞으로 나올 CSS 스펙을 더 정확히 읽을 수 있다.
- **CSS 캐스케이드(Cascade)** — 우선순위가 같을 때는 "나중에 작성된 스타일"이 이긴다. 오늘 배운 우선순위와 함께 캐스케이드 알고리즘 전체를 알아두면 스타일 충돌을 훨씬 빠르게 디버깅할 수 있다.
- **속성 선택자의 대소문자 옵션(`i`, `s`)** — `div[class$=class i]`처럼 대소문자 구분 여부를 지정하는 옵션이 있다. 실무에서 사용자 입력값 등을 다룰 때 유용하다.
